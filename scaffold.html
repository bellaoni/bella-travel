✈️ 신규 여행 생성 도구

Bella Travel — T5 Scaffold. 아래 정보만 입력하면 TRIP_ID가 전 파일에 자동 치환되고, GEO_COORDS는 빈 상태로 초기화되며, 교통정보 카드는 data.js 기반 템플릿으로 생성됩니다. 생성된 zip을 GitHub 새 레포에 업로드하면 됩니다(터미널 불필요, Safari로 가능).

업로드 순서 (아이패드 Safari)

  1. GitHub에서 새 레포 생성 (이름 = 위에서 입력한 TRIP_ID와 동일하게)
  2. 다운로드된 zip을 압축 해제 (파일 앱에서 "압축 풀기")
  3. 레포의 "Add file → Upload files"로 폴더째 끌어다 놓기 (shared-core, .github/workflows 하위폴더 구조 유지)
  4. Settings → Pages에서 GitHub Actions로 배포 활성화
  5. 이후 일정/장소/교통정보 등 실제 콘텐츠는 Claude와 대화하며 data.js에 채워나가기
  6. shared-core(popup.js/theme.js/attachments.js/backup.js/entry-source.js/sw-lifecycle.js/offline-tiles.js)는 이 scaffold.html이 원본(정본)입니다. 새 레포는 생성 시점 스냅샷이므로, 정본이 바뀌어도 자동 반영되지 않습니다. 새 레포에서 이 파일들을 수정했다면, 다음 여행 생성 전에 정본과 diff를 확인하세요
